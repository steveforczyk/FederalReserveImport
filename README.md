# FederalReserveImport
Matlab Scripts to Import Selected Federal ReserveFinancialData
This folder contains A large set of scripts to import data from the Federal Reserve Website. The intent is to run this one time to create a desired database of Federal Reserve Data to be used in stock market portforlio analysis and selection.
The Federal Reserve data based contains hundreds of thousands of tables and plots. This package is aimed at importing a small selection of these databases. The ImportFredData.m file is the executive routine for
this process.
